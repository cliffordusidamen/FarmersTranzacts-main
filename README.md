# FarmersTranzacts
Agricultural eCommerce project. This is the main code base containing all business logic for the entire project. This project serves as REST API Backend for two(2) other applications:

- [Admin](https://github.com/cliffordusidamen/FarmersTranzacts-admin)
- [Seller/Vendor](https://github.com/cliffordusidamen/FarmersTranzacts-seller) 

### Tech Stack
- PHP 7.4+ ([Laravel framework](https://laravel.com), with [Sanctum](https://laravel.com/docs/8.x/sanctum), [Jetstream](https://jetstream.laravel.com/2.x/introduction.html))
- MySQL
- HTML & CSS ([Bootstrap 4.6](https://getbootstrap.com/docs/4.6/getting-started/introduction/))
- Javascript ([InertiaJS](https://inertiajs.com/) and [Vue.js](https://v3.vuejs.org/)
